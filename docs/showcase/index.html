What is this

A domain layer that codifies the math, fairness, and money rules of real iGaming.

wagerforge is a single, self-contained Claude Code plugin. Each skill captures the distilled top-tier insight — the place where the obvious approach quietly ships a bug: a confidently-precise but wrong RTP, a double-pay in the crash/retry gap, a verifier that just trusts the house, a folk "modulo bias" that isn't the real exploit.

It also bundles the generic engineering-process skills (brainstorm, plan, TDD, debug, review), vendored from superpowers (MIT, © 2025 Jesse Vincent). No separate plugin required.

  • Skill is the source of truth

    Knowledge is written once in a skill. Commands, agents, and hooks stay thin and reference skills by name.

  • Server-authoritative always

    The client renders server-resolved results. It never computes payouts, RTP, or outcomes.

  • Correctness is law

    Constraints C1–C14 encode the corrected statement from the spec — never the refuted folk version.

  • Opinionated default stack

    TS + PixiJS/Phaser + Node + decimal.js by default, with a concept mapping for other stacks.

Install

A single self-contained plugin — no companion install.

The /plugin commands below are run inside Claude Code — they are built-in commands, not shell commands.

  1. 1

    Add the folder as a marketplace — point at the directory containing .claude-plugin/marketplace.json.

  2. 2

    Install the plugin from that marketplace (wagerforge is the plugin, wagerforge-dev the marketplace).

  3. 3

    Restart Claude Code so the SessionStart hook loads the using-wagerforge router.

Claude Code 
# 1. Add this folder as a marketplace
/plugin marketplace add ~/Documents/Developments/wagerforge

# 2. Install the plugin
/plugin install wagerforge@wagerforge-dev

# 3. Restart Claude Code, then start any iGaming task by
#    invoking the router skill:
using-wagerforge

Already using superpowers? wagerforge is dual-install safe — it auto-detects the superpowers plugin and defers its bootstrap (no duplication). Its bundled process skills stay available namespaced as wagerforge:* and never override superpowers:*.
